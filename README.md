# Personal Portfolio Website

## Description
This project is a personal portfolio website built using HTML, CSS, and JavaScript. It showcases my skills, projects, and background in a clean and professional format.

The goal of this portfolio is to present my work to recruiters and collaborators while practicing front-end development skills.

## Features
- Responsive modern design
- About me section
- Skills presentation
- Projects showcase
- Contact section
- Smooth navigation
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive design principles
